Convert CUE/BIN to ISO
the right way.

Strip raw CD sectors, extract the data track, and produce a clean ISO 9660 image — all from a native desktop app with drag-and-drop.

Download AppImage Build from source Read the docs

Drag & Drop

Drop a .cue file straight onto the window to load it. No menus required.

Live Progress

Sector-accurate progress bar updated in real time. Conversion runs on a background thread — the UI never freezes.

Native Qt6

No Electron, no JVM, no web runtime. A small native binary that links directly against Qt6 Widgets.

Correct sector stripping

Handles MODE1/2352, MODE2/2352, and MODE1/2048 tracks. Pregap and per-track BINs included.

How it works

1

Select CUE

Drag a .cue file onto the window, or click Browse.

2

Choose output

Click Convert and pick where to save the .iso.

3

Done

Watch the progress bar. The final ISO size and sector count are reported on completion.

Supported track types

Track type Raw sector User data Status Notes
MODE1/2352 2352 bytes 2048 bytes @ offset 16 Supported Standard CD-ROM data track. Most common.
MODE2/2352 2352 bytes 2048 bytes @ offset 24 Supported Mixed-mode / CD-XA discs. Form 1 data extracted.
MODE1/2048 2048 bytes 2048 bytes (direct) Supported Already cooked ISO data — copied as-is.
AUDIO 2352 bytes — Not converted Audio tracks are skipped. A CUE with only audio tracks is rejected.

Quick start

# 1. Clone and enter the directory
git clone <repo-url> iso-converter && cd iso-converter

# 2. Configure (Release build)
cmake --preset release

# 3. Build
cmake --build build/release -j$(nproc)

# 4. Run
./build/release/iso-converter

Requirements

  • CMake ≥ 3.20
  • Qt 6.2+
  • C++17 compiler
  • Linux / macOS / Windows
